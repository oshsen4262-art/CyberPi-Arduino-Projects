CyberPi-Arduino-Firmware

A collection of open-source firmware for the Makeblock CyberPi, written for the Arduino IDE. Each project is in its own folder with its own README and setup steps.

My 3 best projects:
• Light Browser
• Doom
• Bluetooth Speaker

Hardware

Makeblock CyberPi (ESP32-WROVER-B, 128x128 ST7735 display, DAC speaker)
Arduino IDE with the ESP32 board package
Flash Size 8MB with the included partitions.csv

How to use:

Open a project’s .ino file in the Arduino IDE.
Adjust the settings to the instructions told in the .ino or readme if there is one.
Upload it to the CyberPi.
Wait for it to turn on and enjoy!

Notes

No ROMs included
Emulator folders are based on GPL v2 code (Snes9x and Retro-Go) and keep their licenses and credits.
